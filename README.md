# MEDI-HUB · by Belén Murillo
Apuntes de medicina: ECOE, PDF tipo Goodnotes, flashcards y minijuegos. App web estática (un solo `index.html`), alojada gratis en GitHub Pages.

**IA (opcional):** las funciones con Claude (ECOE, etc.) usan tu propia API key de Anthropic, guardada solo en tu navegador (`claude-shim.js`). Sin key, el resto funciona igual.
